
# Portfolio Website — New Design Theme

## 1. Overall Design Direction

### **Theme: “Midnight Orbit”**

A **dark, futuristic, engineering-focused portfolio** built around the idea of *exploration, experimentation, and building useful technology*.

* **Primary background:** Near-black / charcoal.
* **Accent:** Warm orange/amber for important elements and interactive states.
* **Typography:** Clean, modern sans-serif with occasional handwritten-style accents.
* **Visual language:** Thin orbital lines, subtle grids, glowing borders, glassmorphism cards, soft gradients, and technical UI elements.
* **Overall impression:** More like a **high-end developer/product designer portfolio** than a conventional student resume website.

# 13. UI Style

## **Cards**

Cards should use:

* Dark translucent backgrounds
* 1px subtle borders
* 12–18px border radius
* Very soft shadows
* Slight orange glow on hover
* Smooth 200–300ms transitions

## **Buttons**

Primary:

> **View My Work →**

Dark/secondary:

> **Download CV ↓**

Buttons should have strong contrast but remain compact.

---

# 14. Background Treatment

## **Signature Visual Identity**

The background should contain extremely subtle:

* Technical grid
* Orbital circles
* Fine horizontal lines
* Floating dots
* Gradient light
* Large abstract curves

The background must remain **barely visible**.

The goal is:

> **“Technical atmosphere” rather than “cyberpunk decoration.”**

---

# 15. Animation Strategy

## **Keep Animation Purposeful**

### Hero

Slow orbital movement.

### Project Cards

Image zoom + border glow on hover.

### Statistics

Numbers count upward when entering viewport.

### Timeline

Nodes illuminate sequentially while scrolling.

### Skills

Cards slightly lift on hover.

### Navigation

Transparent → slightly opaque background after scrolling.

Avoid excessive particle effects, cursor trails, or spinning 3D objects. Those are common portfolio clichés and usually reduce usability.

---

# 16. The Core Concept

## **The Portfolio Should Tell One Story**

The entire website follows this progression:

> **Curiosity → Learning → Building → Experimenting → Solving → Creating**

So instead of looking like:

> **“Here is my resume.”**

the website communicates:

> **“Here is what I am learning, what I have built, how I think, and what I am going to build next.”**

That positioning is significantly stronger for a student/developer portfolio because it demonstrates **trajectory and capability**, rather than trying to manufacture senior-level experience. 🚀
